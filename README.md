# 18.5th Basic — 학기 중 스터디 레포

인천대학교 앱센터 18.5기 베이직 파트 학기 중(9월~12월) 개인 학습 기록 레포입니다.
방학 중 팀 프로젝트는 이 레포와 별도로 진행합니다.

## 폴더 구조

```
{본인이름}/
├── week01/
├── week02/
├── ...
└── week15/
```

- 자기 이름으로 최상위 폴더를 하나 만들고, 그 안에 `week01`~`week15` 주차 폴더를 만들어 그 주에 작성한 코드/자료를 올려주세요.
- `홍길동(예시)` 폴더가 템플릿입니다. 그대로 복사해서 폴더명을 본인 이름으로 바꾸고 시작하면 됩니다.
- 각 week 폴더 안의 README.md에는 그 주차의 오프라인 세션 내용, 과제, 레퍼런스 링크가 정리되어 있습니다. 참고만 하고 실제 코드/실습 파일을 자유롭게 추가하시면 됩니다.

## 진행 방식 (이슈 → 브랜치 → PR → 코드리뷰)

18기 백엔드 스터디 레포(https://github.com/inu-appcenter/basic-backend-study-18th) 와 동일한 흐름으로 진행합니다.

1. **이슈 생성**: `.github/ISSUE_TEMPLATE`의 "N주차 과제 제출" 템플릿을 사용해서 이번 주차 이슈를 만듭니다. 제목은 `[NN주차] 커리큘럼 범위 - 이름` 형식으로 작성합니다.
2. **브랜치 생성**: 해당 이슈에서 브랜치를 만듭니다. (권장 이름 형식: `week{NN}/{이름}`, 예: `week01/김도영`. 이슈에서 자동 생성되는 이름을 그대로 써도 무방합니다.)
3. **작업 및 push**: 본인 이름 폴더의 해당 week 폴더 안에서 작업하고 커밋/push 합니다.
4. **PR 생성**: `.github/PULL_REQUEST_TEMPLATE.md` 양식에 맞춰 PR을 열고, 연관 이슈 번호를 연결합니다.
5. **코드리뷰**: 멘토(태영, 명재, 도영)가 PR에 리뷰를 남기고, 반영 후 merge합니다.

`.github/CODEOWNERS`의 아이디를 실제 GitHub 아이디로 바꿔두면 PR마다 세 분이 자동으로 리뷰어 지정됩니다.

## 참고

- 커리큘럼 전체 및 레퍼런스 목록은 클럽 노션 페이지를 참고하세요.
- 과제 3회 이상 미제출 / 멘토 경고 2회 누적 시 퇴출 규정이 적용됩니다.
